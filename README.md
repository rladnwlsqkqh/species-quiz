# 생물 동정 퀴즈

태블릿용 생물 동정(이름 맞히기) 퀴즈입니다.

1. 메인 화면에서 분류군(조류 / 어류 / 곤충) 선택
2. 해당 분류군에서 무작위로 1문제 출제 (같은 문제가 연속으로 나오지 않음)
3. 보기를 고르면 정답 표시
4. "메인으로 돌아가기"로 처음 화면 복귀

## 문제 추가하기

`data.js`의 해당 분류군 `questions` 배열에 항목을 추가하고, 사진은 `images/` 폴더에 넣으면 됩니다.
문제가 하나라도 있는 분류군은 메인 화면에서 자동으로 활성화됩니다.

```js
{ id: "bird-01", image: "images/birds/magpie.jpg", answer: "까치",
  choices: ["까치", "물까치", "어치", "까마귀"] }
```

## 출제 방식

분류군마다 10문제를 섞어서 차례로 내고, 다 돌면 다시 섞습니다. 새로 섞을 때 직전 문제가 맨 앞에 오지 않도록 해서
같은 문제가 연속으로 나오지 않습니다. 순서는 브라우저에 저장되어 새로고침해도 이어집니다.
보기 순서도 매번 섞입니다.
